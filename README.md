# Agents-

Стартовый HTTP-сервер на Python 3.10 или новее. Внешние зависимости не нужны.

## Запуск

```sh
python3 app.py
```

По умолчанию сервер слушает `127.0.0.1:8000`. Адрес и порт можно задать
переменными `HOST` и `PORT`.

## Проверка

```sh
curl --fail http://127.0.0.1:8000/
curl --fail http://127.0.0.1:8000/health
```

`/` возвращает приветствие, `/health` — `{"status": "ok"}`,
неизвестные пути — HTTP 404. Остановить сервер можно сочетанием Ctrl+C.
